# 손으로 받아 온 자료

API 가 없어 **사람이 내려받아야 하는** 원자료를 둔다. 저장소에 넣는 이유는 하나다 —
다시 받을 수 없으면 재현할 수 없기 때문이다. 파일 이름에 받은 날짜를 박고, 메타자료를
나란히 둔다.

여기 있는 것은 **자동으로 갱신되지 않는다.** `scripts/checkup.py` 가 얼마나 묵었는지
보고 알려 준다.

건축물대장은 (시군구코드 + 법정동코드)로 조회하는데 **API 가 법정동 목록을 주지
않는다.** 그래서 받아 둔다. 우리 17개 구에 439개(동 198 + 리 241)이고, 아파트가
있는 법정동만 세면 177개뿐이다 — 단독주택 멸실을 잡으려면 그 차이가 구멍이 된다.

폐지된 법정동은 뺐다(`존재` 만 남김). 시군구 자체 코드(`XXXXX00000`)도 뺐다.

경기도 **시군구별** 일반가구수·주택수(유형별)·주택보급률이 연 단위로 들어 있다.
공표 통계 중 우리 지역을 시 단위로 주는 몇 안 되는 자료다 — 한국부동산원 공급 표는
시도까지만 온다([docs/supply.md](../../../docs/supply.md)).

### 쓰기 전에 알아야 할 것

메타자료(`.meta.txt`)에 적힌 것과 우리가 재서 확인한 것을 함께 적는다.

- **경기 합계 일반가구수가 R-ONE 가구수와 0.0% 일치한다.** 같은 통계를 시군구까지
  내린 것이 맞다(2015·2018·2020·2022·2024 대조).
- **2015~2020 은 시군구 값이 전부 `-` 다.** 경기 합계만 있다. 긴 시계열을 못 만든다.
- **2008년에 정의가 바뀐다.** 일반가구수가 2001~2007 은 '총가구 − (단독·비혈연·집단·
  외국인가구)', 2008년부터는 '일반가구(비혈연·1인 포함, 집단·외국인 제외)' 다.
  우리 8개 시 합이 2008년에 +246,344 로 튀는 것이 이것이다.
- **2021년에 주택수 출처가 바뀐다**(경기도 주택정책과 → 주택총조사). 메타자료가
  "20년까지의 계산값과는 다를 수 있음" 이라고 적어 두었다. 보급률이 93.3% →
  86.3% 로 꺾이는 자리다.
- **시군구 보급률은 쓸 수 없다.** 공표값이 `...` 로 비어 있고, 주택수÷가구수로
  직접 만들면 경기 합계가 88.7% 가 나오는데 공표값은 99.4% 다(11%p 차이).
  보급률은 국토교통부 **추계자료**이고 다가구주택을 구분거처로 세기 때문이다.
  직접 나눈 값을 '보급률' 이라고 띄우지 않는다.

그래서 **2021~2024 구간의 가구수와 주택수만** 쓴다.

### 다시 받는 방법

위 주소에서 통계표를 열고 시군구·전체 연도를 골라 CSV 로 내려받는다. 메타자료는
같은 화면의 '통계표 메타자료' 에서 받는다. 받은 뒤 파일 이름의 날짜를 바꾸고
`python -m scripts.ingest_gg_housing` 을 돌린다.

KOSIS OpenAPI 키를 받으면 자동화할 수 있다. 지금은 키가 없어 손으로 받는다.
