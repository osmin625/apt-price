# 단기 매매 — 차트 기법 저장소

주식 '단기 매매' 탭이다. **차트 모양과 지표로 며칠~몇 주를 보고 사고파는 기법을 한곳에 모아, 원리·규칙·예시·
함정·원전을 설명한다.** 같은 꼴의 장기 투자 탭은 [가치평가 기법 저장소](valuation.md) 가 다룬다.

## 왜 저장소인가

2026-11-12 요청 — 장기 투자 탭과 단타 탭을 더하되, **설명이 초점**이다. 결정은 grilling 으로 하나씩 정했다.

| 물음 | 정한 것 |
|---|---|
| 무엇을 보여 주나 | 기법 저장소 — 기법마다 카드 하나, 누르면 설명 창 |
| 지금 자료(일봉 종가)로 못 재는 기법 | 올린다. 예시 데이터로 설명한다 |
| 신호를 내나 | 지금 상태 + 과거 성적까지. '사라·팔아라' 는 쓰지 않는다 |
| 과거 성적의 기준선 | 아무 날이나 고른 기저율 · 사서 들고 있기, 거래 비용 포함 |
| 예시 | 실제 지수에서 그 모양이 나온 구간이 먼저, 없으면 합성 |
| 이름·순서 | 지수 분석 · 장기 투자 · 단기 매매 — 일봉이라 며칠~몇 주가 중심이어서 '단타' 대신 '단기 매매' |
| 올리는 순서 | ① 설명·합성 예시 → ② 단기의 실제 사례·지금 상태·과거 성적 → ③ 장기 지수 평가 넷(새 출처) |

지금 화면은 ② 까지다 — 종가로 재는 기법에 지금 상태·과거 성적·실제 사례가 붙었다(아래 '실제 지수에 돌리는 법').

## 기법과 묶음

목록·글·예시는 `frontend/src/stock/techniques/short.js` 한 곳에 있다. 화면(`frontend/src/stock/views/TechniqueView.jsx`)은 그것을 그대로
깐다 — 기법을 더하면 항목 하나를 더한다.

| 묶음 | 기법 |
|---|---|
| 추세·돌파 | 이동평균 교차 · MACD · 신고가 돌파(돈치안·터틀) |
| 역추세·과열 | RSI · 볼린저 밴드 · 스토캐스틱 · 이격도 |
| 차트 패턴 | 헤드앤숄더 · 이중 바닥·천장 · 삼각 수렴 · 깃발·페넌트 · 컵앤핸들 · 지지·저항 |
| 캔들·거래량·장중 | 망치형 · 장악형 · 도지 · 거래량 실린 돌파 · OBV · 갭 메우기 · VWAP · 스캘핑 |

항목마다 `need` 가 그 기법을 실제 지수에 돌리는 데 필요한 자료다 — `close`(종가로 잼)·`ohlc`(고가·저가)·`volume`·
`intraday`(분봉). 지금 받는 것은 [지수 일봉 종가](indices.md#출처) 뿐이라 `close` 만 실제로 돌린다.

## 예시와 실제

- **합성 가격은 모양만 정한다.** 꼭짓점을 이은 선에 씨앗을 정한 잡음(이어진 AR(1))을 얹는다(`frontend/src/stock/techniques/synth.js`
  `path`). 열 때마다 바뀌면 설명 글('두 번째 바닥에서')이 어긋나서 씨앗을 고정했다.
- **신호는 규칙을 돌려 얻는다.** 진입·청산 표시를 손으로 찍으면 '규칙대로라면 여기서 난다' 가 아니라 '여기서 났으면
  좋겠다' 가 된다. 이동평균 교차는 바닥보다 한참 늦게 찍힌다 — 그게 그 기법이다.
- **합성 예시의 목선·추세선은 사람이 긋는다.** 합성 가격의 계획한 꼭짓점 근처에서 실제 꼭대기·바닥을 찾아
  긋는다(`peak`). 실제 지수에서는 정해 둔 탐지 규칙으로만 찾는다(아래 '패턴 탐지 규칙').
- **실제 사례가 먼저다.** 창의 예시는 실제 지수 사례가 있으면 그것을, 없으면 합성을 먼저 보인다. 단추로 합성 예시도 볼 수
  있다 — 실제 사례는 모양이 지저분해 '무엇을 보라는지' 는 합성이 더 잘 보여 준다.
- **캔들·거래량은 지어낸다.** 종가에서 시가·고가·저가·거래량을 만들고(`bars`), 설명할 날의 캔들만 모양을 정한다.
- **가격 축에 숫자를 적지 않는다.** 합성 가격이라 값에 뜻이 없고, 숫자가 있으면 실제 지수로 읽힌다.
- 창의 예시 제목 옆에 늘 '합성 데이터' 배지를 단다.

## 실제 지수에 돌리는 법

계산은 `backend/app/stock/trading.py`, 응답은 `/api/stock/short-term`(정적 사이트에도 싣는다), 화면은
`frontend/src/stock/components/LiveSection.jsx`. 정한 것과 이유:

| 정한 것 | 이유 |
|---|---|
| 신호 **다음 거래일 종가**에 체결 | 그날 종가를 보고서야 신호를 안다. 같은 종가에 체결하면 하루치 미래를 본 셈이다 |
| 편도 비용 0.1%, 사서 들고 있기도 살 때 한 번 | 지수 ETF 의 수수료·호가 차이 어림. 잦은 매매일수록 비용이 쌓이는 것을 성적에 담는다 |
| 쉬는 동안 수익 0 | 예금 이자를 넣으면 금리 계열이 하나 더 들어온다. 규칙이 시장 밖에 있는 비용을 과하게 보이게 하는 쪽이라 화면 Hint 에 적었다 |
| 기저율 = 아무 날 n 개의 평균을 2,000번 뽑은 95% 범위 | 오르는 장에서는 아무 날이나 사도 번다. 신호 뒤 평균이 플러스인 것은 아무것도 말하지 못한다 |
| 같은 쪽 신호가 h 거래일 안에 또 나면 하나로 | 몰려 난 신호가 한 구간을 여러 번 세면 범위가 실제보다 좁아 보인다 |
| 신호 5번 미만은 범위·판정을 내지 않음 | 두세 번의 평균은 우연과 구별되지 않는다 |
| 실제 사례 = 뒤 60거래일이 다 지난 **가장 최근** 신호 | 보기 좋은 것을 고르면 기법이 실제보다 좋아 보인다. 규칙으로 고른다 |

진입·청산이 있는 규칙(이동평균 교차·MACD·돈치안·RSI·볼린저·이격도)은 규칙대로 사고판 결과를 사서 들고 있기와 같은 기간으로
견준다. 패턴은 일회성 신호라 '신호 뒤 h 거래일' 만 본다. 지지·저항은 박스를 벗어나는 날만 잰다 — 박스 안에서 사고파는 판은
선을 사람이 고르는 몫이 커서 규칙으로 못 박지 않았다.

## 패턴 탐지 규칙

사람 눈으로 고르면 지나고 나서 어디서나 보인다(헤드앤숄더 창의 함정 셋째). 그래서 두 단계로 정해 둔다.

1. **꼭짓점은 지그재그로.** 종가가 직전 꼭대기(바닥)에서 3% 되돌면 그 꼭대기(바닥)를 확정한다. 꼭짓점은 **확정된 날부터만**
   쓴다 — 꼭대기는 지나고 나서야 꼭대기이고, 그걸 그날 안 것처럼 쓰면 패턴이 기막히게 들어맞는다.
2. **패턴은 연속한 꼭짓점의 높이 관계로.** Lo·Mamaysky·Wang(2000, 'Foundations of Technical Analysis')의 정의를 따랐다.
   '비슷한 높이' 는 3% 안이다. 마지막 꼭짓점이 확정된 날부터 다음 꼭짓점이 확정되기 전까지 돌파를 기다리고, 종가가 선을
   넘는 첫날이 신호다.

| 패턴 | 꼭짓점 | 신호 |
|---|---|---|
| 헤드앤숄더·역 | 다섯 — 가운데가 가장 높고(낮고) 양 어깨·두 골짜기가 비슷 | 두 골짜기를 이은 목선 돌파 |
| 이중 바닥·천장 | 셋 — 양 끝이 비슷하고 20거래일 넘게 떨어짐 | 가운데 꼭짓점 돌파 |
| 삼각 수렴 | 다섯 — 꼭대기는 낮아지고 바닥은 높아짐 | 어느 쪽 선이든 벗어나는 쪽 |
| 깃발 | 셋 — 30거래일 안 6% 넘는 깃대, 깃대 절반 안쪽 되돌림 | 깃대 끝 돌파(깃대 길이 안에) |
| 컵앤핸들 | 넷 — 12~33% 깊이·35거래일 넘는 컵, 가장자리 5% 안, 위쪽 절반의 손잡이 | 오른쪽 가장자리 돌파(컵 절반 길이 안에) |
| 지지·저항(박스) | 다섯 — 꼭대기끼리·바닥끼리 비슷 | 박스를 벗어나는 쪽 |

되돌림 3%·허용 3% 는 **패턴이 몇 번 잡히나만 보고** 골랐다(2026-11-12). LMW 의 1.5% 와 5% 되돌림으로는 S&P 500 10년에 박스·깃발·컵이
하나도 안 잡혔다. 성적을 보고 고르지 않았다 — 성적으로 고르면 과거에 맞춘 규칙이 된다. 숫자는 `trading.py` 머리 주석에 있다.

미래를 안 보는지는 `scripts/verify_short_rules.py` 가 잘라 낸 계열로 다시 돌려 본다. 다음 날을 엿보는 규칙을 일부러 넣어 그 검사가
걸리는지도 본다.

## 글

창에 나가는 글은 지식만이다 — 정의, 규칙, 원전(사람·책·해), 알려진 한계. **이 기법이 지금 통하는지, 성적이 어땠는지는
적지 않는다**(루트 CLAUDE.md '화면 문구에는 시간이 지나도 맞는 것만'). 그건 재서 응답으로 붙인다(위 '실제 지수에 돌리는 법').

원전은 기억이 아니라 널리 인용되는 출처로 맞춘다. 근거가 흐린 일화(MACD 기간이 주 6일 거래에서 왔다는 설)는 넣지 않았다.
