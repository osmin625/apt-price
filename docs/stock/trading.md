# 단기 매매 — 차트 기법 저장소

주식 '단기 매매' 탭이다. **차트 모양과 지표로 며칠~몇 주를 보고 사고파는 기법을 한곳에 모아, 원리·규칙·예시·
함정·원전을 설명한다.** 같은 꼴의 장기 투자 탭은 [가치평가 기법 저장소](valuation.md) 가 다룬다.

## 왜 저장소인가

2026-11-12 요청 — 장기 투자 탭과 단타 탭을 더하되, **설명이 초점**이다. 결정은 grilling 으로 하나씩 정했다.

| 물음 | 정한 것 |
|---|---|
| 무엇을 보여 주나 | 기법 저장소 — 기법마다 카드 하나, 누르면 설명 창 |
| 지금 자료(일봉 종가)로 못 재는 기법 | 올린다. 예시 데이터로 설명한다 |
| 신호를 내나 | 지금 상태 + 과거 성적까지. '사라·팔아라' 는 쓰지 않는다 |
| 과거 성적의 기준선 | 아무 날이나 고른 기저율 · 사서 들고 있기, 거래 비용 포함 |
| 예시 | 실제 지수에서 그 모양이 나온 구간이 먼저, 없으면 합성 |
| 이름·순서 | 지수 분석 · 장기 투자 · 단기 매매 — 일봉이라 며칠~몇 주가 중심이어서 '단타' 대신 '단기 매매' |
| 올리는 순서 | ① 설명·합성 예시 → ② 단기의 실제 사례·지금 상태·과거 성적 → ③ 장기 지수 평가 넷(새 출처) |

지금 화면은 ① 까지다. 카드에 지금 상태·성적이 없는 것은 그래서다.

## 기법과 묶음

목록·글·예시는 `frontend/src/stock/techniques/short.js` 한 곳에 있다. 화면(`frontend/src/stock/views/TechniqueView.jsx`)은 그것을 그대로
깐다 — 기법을 더하면 항목 하나를 더한다.

| 묶음 | 기법 |
|---|---|
| 추세·돌파 | 이동평균 교차 · MACD · 신고가 돌파(돈치안·터틀) |
| 역추세·과열 | RSI · 볼린저 밴드 · 스토캐스틱 · 이격도 |
| 차트 패턴 | 헤드앤숄더 · 이중 바닥·천장 · 삼각 수렴 · 깃발·페넌트 · 컵앤핸들 · 지지·저항 |
| 캔들·거래량·장중 | 망치형 · 장악형 · 도지 · 거래량 실린 돌파 · OBV · 갭 메우기 · VWAP · 스캘핑 |

항목마다 `need` 가 그 기법을 실제 지수에 돌리는 데 필요한 자료다 — `close`(종가로 잼)·`ohlc`(고가·저가)·`volume`·
`intraday`(분봉). 지금 받는 것은 [지수 일봉 종가](indices.md#출처) 뿐이라 `close` 만 ② 단계에서 실제로 돌린다.

## 예시와 실제

- **합성 가격은 모양만 정한다.** 꼭짓점을 이은 선에 씨앗을 정한 잡음(이어진 AR(1))을 얹는다(`frontend/src/stock/techniques/synth.js`
  `path`). 열 때마다 바뀌면 설명 글('두 번째 바닥에서')이 어긋나서 씨앗을 고정했다.
- **신호는 규칙을 돌려 얻는다.** 진입·청산 표시를 손으로 찍으면 '규칙대로라면 여기서 난다' 가 아니라 '여기서 났으면
  좋겠다' 가 된다. 이동평균 교차는 바닥보다 한참 늦게 찍힌다 — 그게 그 기법이다.
- **패턴의 목선·추세선은 규칙이 아니라 사람이 긋는다.** 합성 가격의 계획한 꼭짓점 근처에서 실제 꼭대기·바닥을 찾아
  긋는다(`peak`). 실제 지수에서 찾으려면 정해진 탐지 규칙이 필요하다 — 없이 찾으면 사후 해석이 된다(② 의 숙제).
- **캔들·거래량은 지어낸다.** 종가에서 시가·고가·저가·거래량을 만들고(`bars`), 설명할 날의 캔들만 모양을 정한다.
- **가격 축에 숫자를 적지 않는다.** 합성 가격이라 값에 뜻이 없고, 숫자가 있으면 실제 지수로 읽힌다.
- 창의 예시 제목 옆에 늘 '합성 데이터' 배지를 단다.

## 글

창에 나가는 글은 지식만이다 — 정의, 규칙, 원전(사람·책·해), 알려진 한계. **이 기법이 지금 통하는지, 성적이 어땠는지는
적지 않는다**(루트 CLAUDE.md '화면 문구에는 시간이 지나도 맞는 것만'). 그건 ② 에서 재서 응답으로 붙인다.

원전은 기억이 아니라 널리 인용되는 출처로 맞춘다. 근거가 흐린 일화(MACD 기간이 주 6일 거래에서 왔다는 설)는 넣지 않았다.
