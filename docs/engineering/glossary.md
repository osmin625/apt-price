# 용어집

코드 이름이 무슨 뜻인지, 새 이름을 무엇으로 지을지. 화면 이름과 코드 이름이 다른 곳,
같은 말이 두 뜻으로 쓰일 뻔한 곳을 모았다.

이 문서에는 **이름과 뜻**만 적는다. 무엇이 어디 있는지는
[architecture.md](architecture.md), 값을 어떻게 구하는지는 그 주제의 문서가 답한다.

## 이름을 짓는 규칙

- **자산 이름을 도메인 개념에 쓰지 않는다.** `stock` 은 주식 자산(`app/stock`,
  `src/stock`, `stock.db`)의 이름이다. 부동산의 '주택 재고' 는 `housing_stock` 이다.
  공급 분석의 교차검증 값이 `stock_delta` 였던 것을 `housing_stock_delta` 로 바꿨다 —
  주식 패키지가 생기면 `grep stock` 의 절반이 엉뚱한 것을 가리킬 자리였다.
  `verify_sync` 가 부동산 폴더 안의 맨 `stock` 이름을 잡는다.
- **화면 이름은 바뀌어도 탭 id 는 안 바꾼다.** 링크(`#macro/overlay`)와 정적 파일 경로가
  id 에 묶여 있다. 그래서 id 와 화면 이름이 어긋난 탭이 있다(아래 표).
- **새 개념은 이 표의 말을 먼저 찾는다.** 없으면 만들고 여기 한 줄 더한다. 같은 것을 두
  이름으로 부르기 시작하면 검색이 반쪽만 찾는다.

## 자산과 공통

| 코드 | 뜻 |
|---|---|
| 자산(asset) | 분석 대상의 큰 갈래. 패키지 `app/<자산>`, 화면 `src/<자산>`, DB 파일 하나씩. 자산끼리는 import 하지 않는다 |
| `realestate` | 부동산 자산 — 경기 남부 아파트 |
| `stock` | 주식 자산. 주택 재고가 아니다 |
| `macro` (패키지) | 자산을 건너 쓰는 거시 계열(`app/macro`, `macro.db`). 부동산 탭 id `macro`('가격 분석')와 다르다 |
| `core` | 자산이 같이 쓰는 설정·DB 엔진·DB 파일(`core/config.py`, `core/db.py`, `core/dbfile.py`) |
| `shared` | 자산과 무관한 화면 부품(`src/shared/`). 자산 폴더를 모른다 |
| 정적 사이트 · 스냅샷 | 응답을 미리 JSON 파일로 내보낸 공개 사이트(`export_static.py`). 서버 없이 뜬다 |
| `static` (탭) | 그 탭이 정적 사이트에 실리는가 — `src/realestate/tabs.jsx` |

## 주식 — 탭 id 와 이름

| id · 이름 | 뜻 |
|---|---|
| `index-analysis` · 지수 분석 | 경제지표가 S&P 500·KOSPI 에 미친 영향(맨 위, 지표마다 카드)과 다음 1·3개월 수익률 구간(접힌 카드). 옛 id `indices`(지수 예측)는 별칭으로 남겼다 |
| `long-term` · 장기 투자 / `short-term` · 단기 매매 | 주식의 기법 저장소 두 탭. 목록은 `frontend/src/stock/techniques/long.js`·`short.js`, 화면은 둘 다 `TechniqueView`. '단타' 라 부르기도 하지만 일봉이라 며칠~몇 주가 중심이다 |
| 평소 폭 | 지표 1년 움직임의 표준편차. 영향 막대는 '이만큼 움직일 때 지수 몇 %' 다 |
| 발표 시차 `pub_lag` | 그 달 값을 몇 달 뒤에 알 수 있나. '그 뒤' 수익률은 그때부터 센다 |
| `kind` (지표) | `diff` 1년 변화 %p · `growth` 1년 상승률 % · `level` 수준(미국 장단기 금리차만) |
| 기점(origin) | 예측을 내는 달. 그 월말까지 알려진 것만 쓴다 |
| 기준선 `rw` | 무작위 보행 — 중심 0. 모든 후보가 이것과 견준다 |
| 포함률 · 구간 점수 | 실제가 구간 안에 든 비율 · 폭 + 벗어난 만큼의 벌점(낮을수록 좋음) |
| `market` · `symbol` | 일봉 키의 시장(`KR`·`US`)과 종목·지수 기호. 기호는 시장마다 겹칠 수 있다 |

## 부동산 — 탭 id 와 화면 이름

| id | 화면 이름 | 무엇 |
|---|---|---|
| `regime` | 거시 분석 | 거시 요인이 가격을 어느 쪽으로 미나(거시 국면) |
| `supply` | 공급 분석 | 준공·인허가·착공·멸실 대 적정 공급 |
| `tenure` | 매매·전세·월세 | 점유 형태별 가격과 월 비용 |
| `macro` | 가격 분석 | 한국부동산원 공표 가격을 시군구로 — **id 가 '거시' 가 아니다** |
| `micro` | 매물 분석 | 단지 가격을 움직이는 요인 |
| `model` | 분해 모델 | 헤도닉 적합 결과 |
| `map` | 지도 | 단지 하나하나 |
| `compare` | 호가 입력 | 붙여넣은 매물을 읽어 평가 |
| `ranking` | 호가 분석 | 쌓인 호가의 순위 |

## 부동산 — 모델

|---|---|
